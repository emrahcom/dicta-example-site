# dicta-example-site

Teamboard, a small task list for a team. It is an example site for dicta
actions. You can try dicta-action-harness on it before you use the harness on
your own site.

The site does not use dicta itself. Its action layer is made with the harness,
like on any other site.

## Start it

Requires Node.js 24 or later.

```sh
npm install
npm start
```

Then open http://localhost:8080/ in your browser. Set `PORT` to use another
port.
